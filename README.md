# Dynamic Island LS Color 16

Rootless iOS 16 tweak for native Dynamic Island devices.

Initial test build:
- Changes the native Dynamic Island keyline/border to purple.
- Changes the Lock Screen lock/Face ID glyph to purple.
- Keeps Apple's native Dynamic Island rendering and behaviour.
- No fake/notched-device Dynamic Island code.
- Targets Dopamine/rootless on iOS 16.

The first build uses a fixed purple colour so the hooks can be verified before colour pickers and separate enable switches are added.
